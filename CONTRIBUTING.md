# Contributing

Corrections are welcome: a wrong link, a wrong or missing source, a description that misstates a practice, a translation error.

Open an issue with the **Content correction** form: the node or link id, what is wrong, what it should be, and a source when you have one (a standard and its section, or an author and a publication).

`graph.json` is exported from the private source of the graph, so pull requests are not merged directly. Accepted corrections ship in the next release, and the issue is closed with that version.

A gate verdict or a project route that looks wrong comes from the decision rules, which are not in this repository. Write to support@agile-today.org with the tool call and its receipt hash: every answer is deterministic, so the hash is enough to reproduce it.

Do not paste text from paid standards (PMBOK® Guide, the PRINCE2® manual, BABOK® Guide and others) into issues: name the concept and the section instead.
